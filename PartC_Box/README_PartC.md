# Part C - The box program (2.5 marks)

`Box.asm` draws a black box while any key is pressed and erases it when the key is released.

- Starts at row 27 (K = 27), address 17248
- 20 rows tall
- 64 pixels wide (4 words), from the left edge
- `Box.hack` was produced by my own assembler (`../PartB_Assembler/assembler.py`), not the official one
